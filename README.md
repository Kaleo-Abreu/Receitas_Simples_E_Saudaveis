# 🥗 RS&S - Receitas Simples (Blog Frontend)

> Projeto desenvolvido para praticar a criação de interfaces modernas, estruturação de componentes web e estilização com **Tailwind CSS**.

---

## 📌 Sobre o Projeto

O **RS&S - Receitas Simples** é um modelo de blog focado em culinária saudável, prática e acessível. A interface foi planejada para oferecer uma experiência de navegação limpa, responsiva e intuitiva, destacando conteúdos como receitas rápidas, categorias de refeições e formulários de contato.

---

## 🎨 Paleta de Cores e Estilização

A escolha das cores foi feita para transmitir praticidade e um estilo de vida saudável, utilizando as classes utilitárias do Tailwind CSS:

- **Verde Principal (`#5C7844` / `emerald-700`):** Representa saúde, ingredientes frescos e identidade do blog.
- **Laranja Destaque (`#E87735` / `orange-500`):** Utilizado em botões de ação (CTA) como *Enviar* e *Inscrever-se* para gerar alto engajamento.
- **Cinza & Fundo Claro (`slate-50` / `stone-100`):** Mantém a interface leve e com excelente contraste de leitura.

---

## 🚀 Elementos Praticados

- [x] **Header & Navigation:** Logotipo exclusivo, menu de navegação e barra de pesquisa funcional.
- [x] **Hero Section & Grid de Receitas:** Exibição de cards de receitas com badges de categorias (*Sem Glúten*, *Vegetariano*).
- [x] **Página de Contato:** Formulário completo (*Nome, E-mail, Assunto, Mensagem*) e canal de atendimento direto.
- [x] **Sidebar Informativa:** Bloco com endereço, horário de funcionamento, redes sociais e newsletter.
- [x] **Footer:** Links de navegação rápida e copyright.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica da página.
- **Tailwind CSS:** Estilização responsiva e customização por classes utilitárias.
- **JavaScript (Opcional):** Manipulação de eventos do formulário e menu mobile.
